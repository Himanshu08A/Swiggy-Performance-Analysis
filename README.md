# Swiggy Performance Analysis & Interactive Dashboard

**An exploratory sales and business performance analysis project using Microsoft Excel and Power BI.**

## Project Overview

This project analyzes Swiggy-related restaurant and sales data to understand business performance, identify trends in sales and order activity, compare geographical performance, and communicate findings through an interactive Power BI dashboard.

The analysis focuses on key business performance indicators (KPIs), monthly trends, average order value, and geographical comparisons to understand how different factors contribute to overall performance.

The objective is to transform raw data into meaningful business insights that can support data-driven decision-making.

---

## Project Objectives

The primary objectives of this project are to:

* Analyze overall sales and order performance.
* Evaluate monthly changes in sales and order volume.
* Understand average order value (AOV) and its relationship with order activity.
* Compare sales and order performance across states.
* Identify geographical differences in customer purchasing behavior.
* Build an interactive Power BI dashboard to communicate key metrics.
* Translate analytical findings into clear business observations.

## Analysis Performed

### 1. Overall Sales Performance

Examined the sales data to understand the overall level of business activity and establish a baseline for further analysis.

The analysis provides context for evaluating monthly trends and geographical differences.

### 2. Monthly Sales & Order Trends

Compared January and February performance to understand changes in sales and order activity.

The comparison examined:

* Monthly sales.
* Monthly order volume.
* Average order value.
* Average daily sales.
* Average daily orders.

This comparison helps distinguish changes in total monthly performance from changes in average daily activity.

### 3. Average Order Value Analysis

Evaluated average order value to understand the average transaction value represented by each recorded order.

AOV was considered alongside total sales and order volume rather than as an isolated metric.

An increase in AOV can indicate a higher average transaction value, but it does not automatically imply an improvement in profitability.

### 4. Geographical Performance Analysis

Compared state-level order activity and average order value to identify differences across the geographical categories available in the dataset.

The analysis focused on:

* States contributing the highest order volumes.
* Differences in average order value between states.
* Geographical variations in purchasing behavior.

These comparisons help identify areas that may warrant further investigation.

### 5. Interactive Dashboard Development

Developed a Power BI dashboard to present key performance indicators and make the analysis easier to explore.

The dashboard brings together sales metrics, order trends, and geographical comparisons in a visual format.

It is intended to help users identify performance patterns without manually reviewing the underlying data.

## Key Findings

The following observations emerged from the analysis.

### 1. Monthly Sales Declined in February

Recorded sales decreased from approximately **6.8 million in January to 6.3 million in February**.

This represents an approximate decline of 7.4%.

The decline indicates that total recorded sales were lower in February than in January.

However, monthly sales alone do not explain the cause of the decline.

### 2. Order Volume Decreased

February recorded approximately **2,107 fewer orders than January**, based on the analysis.

The reduction in order volume contributed to the lower monthly sales figure.

Further investigation would be needed to determine whether this change reflects demand, customer activity, data coverage, or other factors.

### 3. Average Order Value Increased Slightly

Despite the reduction in total sales and order volume, average order value increased by approximately ₹1.

This suggests that the average recorded order was slightly higher in value in February.

However, the increase was not sufficient to offset the overall decline in sales.

### 4. Average Daily Activity Increased

Average daily sales and average daily order volume increased in February, according to the analysis.

One important consideration is that February has fewer calendar days than January.

Therefore, monthly totals and daily averages can move in different directions.

This illustrates why comparing both total performance and daily averages can provide a more informative view of business activity.

### 5. Karnataka Recorded More Orders Than Uttar Pradesh

Karnataka recorded approximately twice as many orders as Uttar Pradesh in the dataset.

However, Karnataka's average order value was approximately ₹271, compared with ₹305 for Uttar Pradesh.

This suggests that the state with the higher order volume did not necessarily have the higher average transaction value.

The difference could be investigated further through customer, product, restaurant, or order-level analysis, if those fields are available.

### Interpretation

These findings demonstrate that sales performance should not be evaluated using a single metric.

Total sales, order volume, average order value, and daily averages provide different perspectives on business performance.

Combining these metrics helps distinguish changes in transaction value from changes in the frequency of orders.

## Business Implications

The analysis highlights several areas that could be explored further.

### Investigate the Decline in Monthly Sales

A decline in monthly sales should be examined alongside changes in order volume, average order value, and daily performance.

This can help determine whether the change is primarily associated with fewer orders, lower transaction values, or other factors.

### Explore Geographical Differences

The difference between Karnataka and Uttar Pradesh suggests that order volume and average transaction value should be analyzed separately.

Further analysis could examine product mix, restaurant distribution, customer segments, and order frequency, if the relevant data is available.

### Monitor Multiple KPIs Together

Tracking sales, order volume, AOV, and daily averages together provides a more balanced view of performance.

These metrics can help identify changes that would be less apparent when looking at total sales alone.

*These are potential areas for further investigation, not proven causes or guaranteed business outcomes.*

## Limitations

This project has several limitations to consider when interpreting the findings:

* The results depend on the completeness and accuracy of the available dataset.
* The analysis identifies patterns and differences but does not establish causation.
* The January–February comparison covers a limited period and should not be treated as a long-term trend.
* State-level comparisons may be affected by differences in data coverage or business activity.
* The analysis does not establish profitability unless relevant cost and margin data is available.

Recognizing these limitations is important when using data analysis to support business decisions.
